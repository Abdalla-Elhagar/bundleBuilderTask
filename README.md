https://bundle-builder-task-three.vercel.app

---

## Tech Stack

- React 19
- TypeScript
- Vite
- Tailwind CSS v4
- Context API & useCotext

---

## Data

The application is data-driven using a local `mockData` source.

---

## Getting Started

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```

---

## Notes

- Built with reusable React components.
- Uses local `mockData` as the data source.
- No backend was implemented.
